Agentcoin — portable node for macOS (Apple Silicon)
===================================================

Что это
  Папка с нодой Agentcoin. Ничего не устанавливается: ни служб, ни прав root.
  Данные лежат рядом, в data/. Удалили папку — удалили ноду.

Что нужно
  macOS на Apple Silicon (M1/M2/M3/M4). Node уже внутри (файл node).

Как запустить
  1. Распакуйте архив целиком.
  2. Первый раз: правый клик по start.command → Open → Open
     (или в Терминале: xattr -dr com.apple.quarantine ./start.command).
  3. Дальше — обычный двойной клик по start.command.
  4. Первый запуск копирует снимок цепи в data/chain.json и идёт в сеть
     на @SEED@ — это единственный внешний адрес.

Как проверить, что работает
  В другом окне Терминала:
    curl -s http://127.0.0.1:@PORT@/info
  height должен расти и догнать сеть, tipHash совпасть с публичной нодой.
  Порт по умолчанию @PORT@; другой порт: ./start.command 9340

Как остановить
  Ctrl+C в окне Терминала.

Где данные
  data/chain.json     — цепь
  data/peers.json     — известные пиры (создаётся само)
  data/wallet.json    — кошелёк, если создавали
  backup/             — то, что нода сама сохраняет при перезаписи файлов

Чего нода не делает
  Не открывает порт наружу и не публикует адрес компьютера: слушает только
  127.0.0.1. За домашним NAT она тянет блоки (pull), но другие ноды к ней
  не подключатся. Для этого нужен сервер с публичным портом.

Обновление
  Замените папку app/ и файл chain.json на новые из новой версии. data/ не трогайте.

Столп: нода + встроенный майнинг (кто держит ноду — тот и майнит)
  Двойной клик по start-pillar.command: поднимет ноду, создаст кошелёк столпа
  в data-pillar/ и начнёт майнить на него, когда цепь станет свежей.
  Настоящим столпом сети станете после проброса порта наружу:
  ./start-pillar.command 9340 --public http://ВАШ-БЕЛЫЙ-IP:9340
