Agentcoin — portable node for Windows x64
=========================================

Что это
  Папка с нодой Agentcoin. Ничего не устанавливается: ни служб, ни реестра,
  ни прав администратора. Данные лежат рядом, в data\. Удалили папку — удалили ноду.

Что нужно
  Windows 10/11 x64. Больше ничего: Node уже внутри (node.exe).

Как запустить
  1. Распакуйте архив целиком (не запускайте из ZIP-просмотрщика).
  2. Двойной клик по start.cmd.
  3. Первый запуск копирует снимок цепи в data\chain.json и идёт в сеть
     на @SEED@ — это единственный внешний адрес.

Как проверить, что работает
  В другом окне (PowerShell или curl.exe):
    curl.exe http://127.0.0.1:@PORT@/info
  В ответе height должен расти и догнать сеть, tipHash совпасть с публичной нодой.
  Порт по умолчанию @PORT@; другой порт: start.cmd 9340

Как остановить
  Ctrl+C в окне ноды или просто закрыть окно.

Где данные
  data\chain.json     — цепь
  data\peers.json     — известные пиры (создаётся само)
  data\wallet.json    — кошелёк, если создавали
  backup\             — то, что нода сама сохраняет при перезаписи файлов

Чего нода не делает
  Не открывает порт наружу и не публикует адрес компьютера: слушает только
  127.0.0.1. Поэтому за домашним NAT она тянет блоки (pull), но другие ноды
  к ней не подключатся. Для этого нужен сервер с публичным портом.

Обновление
  Замените папку app\ и файл chain.json на новые из новой версии. data\ не трогайте.

Столп: нода + встроенный майнинг (кто держит ноду — тот и майнит)
  Двойной клик по start-pillar.cmd: поднимет ноду, создаст кошелёк столпа
  в data-pillar\ и начнёт майнить на него, когда цепь станет свежей.
  Настоящим столпом сети станете после проброса порта наружу:
  start-pillar.cmd 9340 --public http://ВАШ-БЕЛЫЙ-IP:9340
