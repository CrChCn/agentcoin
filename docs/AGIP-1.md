# AGIP-1: официальный bootstrap-лист пиров + `GET /peers/bootstrap`

**Статус:** спека → принят; реализация по лестнице ROLLOUT (см. docs/ROLLOUT.md).
**Автор:** оператор + Buffy (агент), дата 2026-10-15.

## Интерфейс
- `bootstrap.json` в корне репо = официальный (манифестный) список стартовых пиров.
  Структура: `{ "bootstrap": ["http://...", ...], "updatedAt": "ISO", "note": "..."}`
- Новый эндпоинт ноды: `GET /peers/bootstrap`
  Ответ: `{ "bootstrap": [...], "peers": [текущий peers.json ноды], "height": N }`
  (bootstrap — из файла репо; peers — живой список самого узла).
- Безопасность: только GET, ничего не мутирует; guard не нужен.

## КритериAcceptance (исполняемый)
`node test/accept-AGIP-1.mjs http://127.0.0.1:<port>` → green, если:
1. GET /peers/bootstrap отвечает 200;
2. JSON содержит массив bootstrap ≥ 1 записи;
3. массив peers присутствует (может быть пустым на свежей песочнице), height — число.

## Запреты
- Не менять consensus/эскроу/мемо-схемы.
- Не трогать формат данных (chain.json и co). Endpoint — только чтение файла + текущее состояние.

## Почему это полезно (империя, шаг 8)
Официальный bootstrap-лист — фундамент федерации (HIRING.md: «внешние ноды»);
новичок берёт стартовый список без доверия к единственной ноде.
