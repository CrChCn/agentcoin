# AGIP-2: BIP-39 сид-фразы — детерминированные кошельки + восстановление

**Статус:** спека → реализована; прогнана по лестнице ROLLOUT (см. docs/ROLLOUT.md).
**Автор:** оператор + Buffy (агент), дата 2026-10-15.

## Мотивация
`createWallet()` генерирует независимую ed25519-пару — если нода потеряет `wallet.json`,
средства адреса восстанавливать нечем (визуально тот же адрес не вывести). BIP-39
(12 слов) даёт человекочитаемый бэкап: энтропия → seed → ключи — детерминировано.

## Интерфейс
- `bip39-lite.mjs`: 2048-словный английский словарь BIP-39, чексумма SHA-256 как в стандарте,
  seed = PBKDF2-HMAC-SHA512(mnemonic, 'mnemonic'+passphrase, 2048),
  ключи ed25519 через HKDF-ветку — формат ключа совместим с `createWallet()` (pkcs8/spki PEM).
- `POST /wallet/create {label, recover:true}` (или `?recover=true`) →
  `{ address, pub, privKey, mnemonic }` — **mnemonic выдаётся ОДИН раз**, в `data/` не сохраняется
  (в wallet.json только флаг `seedWallet: true`).
- `POST /wallet/recover {words, label}` → детерминированно тот же адрес+ключ.
  Если адрес уже есть в реестре — 200 `{ existed: true }` (ключи не перетираем).
  Невалидная мнемоника (чексумма/словарь) → 400 `invalid_mnemonic`.

## Critical consistenze (правила)
- Мнемоника никогда не должна попасть в `data/`, логи ноды, git или чат-логи.
- Восстановление не меняет ключи существующего кошелька (защита от перезаписи через recover).
- Обычный (не-recover) `POST /wallet/create` работает как раньше — без изменений.

## КритерииAcceptance (исполняемые)
`node test/accept-AGIP-2.mjs http://127.0.0.1:<port>` → green, если:
1. `POST /wallet/create {recover:true}` → 201, есть mnemonic из 12 слов, seedWallet-флаг в ответе;
2. `POST /wallet/recover {words}` → 200, адрес = адрес из пункта 1, `existed` — булево
   (на той же ноде честное `existed:true`, т.к. create уже регистрирует кошелёк;
   `existed:false` достижим на чужой ноде/с чистым реестром);
3. повторный recover → 200, адрес тот же — детерминизм;
4. испорченная мнемоника (замена слова) → 400 — тампер-детект;
5. юнит-тесты `bip39-lite` (детерминизм, тампер-детект, label-независимость, 12 слов) — green.

## Запреты
- Не менять адрес-схему и подпись tx (ed25519, txDigest) — recover-кошельки подписывают tx тем же кодом.
- Не логировать mnemonic.

## Почему это полезно
Федерация (HIRING.md) = много агентов со своими кошельками; без сид-бэкапа потеря
ноды = потеря кошелька. Это первый шаг к переносимым идентичностям между нодами.
