# AGIP-8 — «Убегающая нода»: высота ≠ лучшая цепь (зеркальное форк-голосование)

Дата: 2026-10-16 · Статус: внедрено

## Инцидент

9335 «убежала» от кластера: жила на форке с tip 4974+, в то время как остальные
(9341/9342/9336) стояли на 4965–4967 с другим tip. Голосование от 9341 к 9335
показывало картину: развилка на 4885, у тройки хвост из ~86 блоков с работой
29 952, у 9335 — 93 блока с работой 10 944. То есть каноничный (тяжёлый) —
кластер, а 9335 жила на лёгком форке и не собиралась возвращаться.

## Root cause №1 — битые peers.json у 9335

После деплоя AGIP-8 фикс не сработал сразу — вскрылся второй корень: в
`data/peers.json` 9335 лежали заполнители `http://p1, http://p2`. Нода была
Изолирована от periodic sync (ERROR fetch failed у двоих) при живым WS-госсipе.
Замена на реальные адреса 9341/9342/9336 дала мгновенную конвергенцию.

## Root cause №2 — short-circuit по высоте

В `syncOne` стоял short-circuit:

```
if (peerH <= myH) return log("our chain ≥ peer's, ok");
```

Сравнение только по ВЫСОТЕ. Если наша нода выше по блокам, но легче по
суммарной работе (потому что её ретарджет сбросил difficultyBits), она
никогда не замечает, что у пира другая и более тяжёлая цепь. Зеркальная
особенность: fork-vote срабатывает только когда `peerH > myH`. Правило
Биткоина — best chain по СУММАРНОЙ РАБОТЕ, не по высоте, — нарушалось в
направлении «мы короче, но тяжёлее».

## Фикс (sync.mjs)

При `peerH <= myH` и **различающемся tipHash** пира запускаем полноценное
зеркальное голосование:

1. Находим точку развилки сканом `/headers` пира 0..peerH (пагинация ≤2000,
   как в AGIP-7);
2. Сравниваем `chainWork(наш хвост от d)` vs `chainWork(заголовки кандидата)`;
3. Если кандидат тяжелее — `adoptFork` его цепь (we re-org).
4. Страйки — только за доказанные нарушения (`isChainChoiceVerdict`), выбор
   цепи не штрафуется (AGIP-7).
5. Полный префикс + другой tip = невозможное состояние (лжёт tip) — пропускаем
   без голосования и без страйка.

Идентичный по смыслу механизм теперь работает в ОБЕИХ сторонах — независимо
от того, кто «выше» по высоте.
