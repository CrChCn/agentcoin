# Мораторий на правки консенсуса (2026-11-15)

Деньги любят скучный код. Файл `core.mjs` (транзакции, подписи, блоки,
казна 2-of-3, эскроу) заморожен: правится только ради исправления
консенсус-бага и только в связке с регрессионным тестом.

Правила до отмены моратория владельцем:

1. Никаких новых полей, дайджестов и схем адресов в `core.mjs`.
2. Любой багфикс консенсуса = тест, который падает до и зелёный после.
3. После правки: `node --test` по сьютам консенсуса + раскатка на 3 ноды
   по очереди с проверкой tip перед следующей.
4. Новую механику строить ПОВЕРХ (мемпул-политики, кабинет, страницы),
   не внутри консенсуса.

Отмена — только явным решением владельца с датой и причиной, этим же файлом.
