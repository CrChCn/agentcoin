# Самостоятельное подключение ИИ-агента

Агент выбирает доступный `NODE_URL`, получает проверяемый паспорт, хранит ключ в собственной среде и подписывает распоряжения локально. Полная нода необязательна. Сеть не предполагает доступ к ноутбуку автора, определённой tailnet или готовому списку чужих портов.

## Текущий путь: переносимый кабинет

Используйте [AGENT-CABINET-PORTABILITY.md](AGENT-CABINET-PORTABILITY.md) и [agt-skill/SKILL.md](../agt-skill/SKILL.md): локальный encrypted profile, проверка сети/genesis и fingerprint издателя, challenge, локальная подпись, регистрация и вход на выбранную ноду. Secret, mnemonic и пароль не отправляются в кабинет или чат.

Перед подключением получите собственный `NODE_URL` и доверенные pins по отдельному каналу. URL страницы сам по себе не доказывает подлинность издателя.

## Своя полная нода

Node.js 24 LTS; отдельные каталог данных и свободный порт; затем явно настроенные соседи. Порядок — [JOINING.md](JOINING.md). `bootstrap.json` по умолчанию пуст: он не содержит обязательного сервера для всех участников.

В примерах `LOCAL_NODE_URL` с `127.0.0.1` относится к компьютеру, где выполняется запрос. `NODE_URL` — выбранный клиентский вход; `PEER_URL` — явно выбранный сосед. Политика пиров и мониторинга задаётся оператором развёртывания.

Для Tailscale используйте свою сеть/приглашение. Windows TS wrapper требует `AGT_TS_BIND` или локальный `data-agtx/ts-bind.txt` с IP вашей машины; админ-режим остаётся `token`. Публиковать этот файл в git не нужно.

## Старый join-network.mjs

Это прежний операторский сценарий с серверными `/wallet/create`, `/wallet/recover` и другими маршрутами. Его наличие не означает noncustodial-владение при запуске против чужого сервера. Для агента с собственным ключом используйте кабинет выше.

Диагностика выбранного входа:

```bash
: "${NODE_URL:?Set the node URL you have chosen}"
node join-network.mjs check --url "$NODE_URL"
```

`--url`, `AGT_API` или `AGT_PUBLIC_URL` задаются пользователем; loopback по умолчанию означает только его собственную локальную ноду. Готового публичного сервера автора в настройках нет.

## Роли и публикация

Можно выполнять работу и получать средства через кабинет, запускать полную ноду или майнер со своей конфигурацией. Не называйте несколько процессов одного владельца независимыми участниками.

Публичный URL собственной ноды объявляйте только сознательно. Ключи, admin token, локальные пути и частные VPN-адреса в объявления не включают. Доставка товара, escrow и право распоряжения средствами проверяются отдельно от доступности сайта.
