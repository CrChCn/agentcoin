## 6. «×234» — это коэффициент сжатия, а не множитель ёмкости

На главной странице в октябре 2026 показывалось «сжатие ×234» (зафиксировано в `backup-zoo-20261113/tmp/tmp-inc01/issue-latest*.txt`). В ledger реально лежит `compressionRatio` = **233,3 во всех 200 эпохах** (min = median = max = 233.3).

Откуда берётся: константы `cloud.mjs` — `BLOCK_BYTES_ESTIMATE = 350` Б/блок, `EPOCH_SIZE = 64` блока, `ARCHIVE_BYTES = 96` Б на эпоху:

```
350 × 64 / 96 = 233,33…
```

То есть «×234» — округление модельного коэффициента сжатия журнала эпох (оценка «сколько байт цепи заменяет байт архива»), а не прирост диска и не множитель квоты. Связывать его с 891,5 как «квоту ×234» нельзя: величины разной природы.

## 10. Источник 891,5 и ×234: публичный production API (найдено 20.11.2026)

Метод — два GET-запроса к публичному API, без записи и без доступа к серверу:

```bash
curl -s "https://agentcoin.work/cloud/stats"
curl -s "https://agentcoin.work/cloud/ledger?n=500"
```

`/cloud/stats`, снимок `2026-11-20T16:01:21Z`, `stale:false`, `snapshot_ageSec:23`:

```
cloudGB 895.55 · fundAGT 89555 · ledgerLines 17916 · epochsClosed 240
compression.ratioNow 234.1 · archiveBytesNow 26784 · rawBytesNow 6270600
```

`/cloud/ledger?n=500` (total 17 916) содержит ровно нужную строку:

```json
{"h":51926,"type":"cloud_fund","agt":5,"gb":"891.500000","blk":"005311a016536eac","at":1795185910739}
```

- `at = 1795185910739` → **2026-11-20T14:45:10.739Z**.
- Ряд растёт по 0,05 GB на блок: 890,55 (h 51 907) → **891,5 (h 51 926)** → 895,55 (h 52 007, 16:01:22Z).
- `ratioNow = 234,1`, то есть на витрине `×234` как `toFixed(0)`.

**Вывод:** «891,5 VGB» и «×234» — значения живого учёта CloudLedger на ноде-эмитенте около 14:45 UTC 20.11.2026, то есть автор объявления прочитал их с витрины agentcoin.work. Это не выдумка и не ошибка счёта, но и не физическое хранение: 891,5 — историческая точка ряда, а не текущее значение (на 16:01Z — 895,55 и ×234,1).

Локальный ledger (`data/cloud/cloud.json`, 13.11, h 41 995) даёт 1649,30 — это другая копия DATA_DIR, к цифре объявления отношения не имеет.
