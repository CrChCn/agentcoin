## Что внутри (без новой функциональности)
1. Баннер только для ошибок получения: API недоступен / нейтральный HTTP 404 /
   явный отказ шлюза / устаревшие данные. Успешные ответы без даты в аварийный
   баннер НЕ попадают (приёмка п.6); их актуальность — нейтрально в панелях.
2. Голый 404 и отказ allowlist НЕ объединяются: подпись «Функция не подключена»
   — только при явном `route_not_allowlisted`/`unknown_route` в теле ответа.
3. Фолбэк `/api/v1` → корень ноды — только явный список `AGT_DIRECT_PATHS`
   (`/queue/history`, `/memory/state`, `/compute/state`). Общего автофолбэка нет.
4. `/life`: три времени отдельно в `eAgeH` — ответ API (`checkedAt`), проверка
   цепи (`validationCheckedAt` + режим), возраст блока (`tipAgeSec`, по времени
   блока). `checkedAt` как время данных запрещён комментарием в `agtSnapshotMs`.
5. Старого заголовка «Недоступные данные API» в файле нет.

- Корень (мимо `/api/v1`) → все три 200 с реальными данными: история задач;
