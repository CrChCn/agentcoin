# KEY-COMPROMISE-2026-10-19 — публичные приватные ключи в истории git

> TL;DR: 4 кошелька первого коммита (2026-10-14) име-triggered их приватные ключи
> публично в git-истории (балания ВСЕ нулевые, средства не потеряны). Дела:
> признать компромисс, ключи считать публичными, не использовать. Паспорта и
> issuer никогда в git не попадались.

## Факт

Коммит `2fc8525` (самый первый коммит репозитория, «agent-native PoW chain», 2026-10-14)
содержал `data/wallets.json` с 4 кошельками и **приватными ключами в открытом виде**:

| label | адрес | баланс на 2026-10-19 |
|---|---|---|
| mark-operator | AGT147e8f694555ea7a9ea25b2666957dc2e4079e02 | **0 AGT** (проверено /balance) |
| agent-1 | AGT23a94748fe92686debc2b27a32ac13d14693e4f2 | **0 AGT** |
| agent-2 | AGT08fe25a17b65e8964b2198beb94a9f44875a7fe0 | **0 AGT** |
| miner-A | AGTf3c7d3b5823406cd712596fe608d10a9c847bd4d | 0 AGT |

Файл удалён из дерева в `03e841d` («Ignore chain/wallet data dirs»), но **остаётся
в истории** — доступен `git show 2fc8525:data/wallets.json` в любом клоне
(и на github.com/CrChCn/agentcoin).

Компромисс документируется по решению оператора 2026-10-19 (без переписывания истории):
переписывание сломало бы hashes всех веток и потребовало перезаписи у всех участников
(risk > benefit при нулевом балансе).

## Статус ключей: СОПРОМАТИЗИРОВАНЫ — НЕ ИСПОЛЬЗОВАТЬ

Эти 4 ключа считают публичными. **Они не должны использоваться**: ни для подписи tx,
ни для номинации в паспорта, ни в качестве держателя казны/出资 emperor. Кто угодно
с доступом к репозиторию может подписать ими транзакции — несоответствие сети
`addressFromPub` будет соблюдено, и любая трата с «бесплатным» балансом всё равно
потребует средства (а их нет) — но появление этих адресов в будущих «грантах»
означает неявное доверие к компрromетированному ключу.

Активный оператор должен запускать все последующие ноды с ФРЕШ-кошельками
(`POST /wallet/create`) и никогда не восстанавливать эти 4 из бэкапов.

## Что было и остаётся чистым (проверено this pass)

1. `data-agents/passports.json` (реестр 2203 паспортов) — **никогда не коммитился**
   (git log --all --diff-filter=A пусто). Живёт только локально и на D:\ диске.
2. `data/identity/identity-issuer.json` (ключ издателя паспортов) — никогда
   не коммитился. Fingerprint `sha256:27639769891af27c` — из публикаций можно
   узи-слой issuer-pub (это само по себе публичное значение, привязка сайта),
   но privKey не проходил через git.
3. `data-agtx/` (holder-wallet, маркер passport.json, comm-wallets.json) — никогда
   не коммитился.
4. `.gitignore` с `data/`, `data-*/`, `data-emperor/`, `emperor-wallet*.json`
   защищает текущее и будущее дерево. `git ls-files` по паспортам/кошелькам — пусто.
5. Паспорт-пакет на D:\Agentcoin-Prototype\passport\ — вне репозитория физически.

## Политика на будущее

- Паспорта/identity/wallet данные НЕ попадают в git (список игнорируемых уже настроен).
- Всё, что транслируется в сеть (адреса, паспорта в ЗАЯВЛЕННОМ виде, tx),— публично
  по дизайну блокчейна; приватные ключи — только локально/на носителе.
- Для будущих паспортов-раздач: ключ издателя — на отдельном носителе/в vault
  (тот же принцип R-10: один носитель ≠ независимая схема).
- Если когда-либо будет запланирована raised-активность через mark-operator и
  аналогичные — сначала убедиться, что адрес создан заново с новым ключом.
