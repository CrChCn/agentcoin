# СЦЕНАРИИ РАЗВИТИЯ ИМПЕРИИ — количественная модель (2026-10-16)

Все числа взяты из живой сети и констант [core.mjs](../core.mjs) на момент
написания (высота ≈5020). Модель пересчитывается тем же кодом, который крутит
сеть, — это экстраполяция фактов, не фантазия.

## Сценарии

### Сц1 — «Устойчивый микро-кластер» (базовый, пессимистичный)

4→8 нод, все на одной/двух машинах. Макро-факт: ноды всё ещё физические клоны.
Джобы и DXE — экспертные, без внешних. Экономика ≈ сейчас: 50 AGT/блок, supply
растёт, Джобы 15-20/мес (rост за счёт digest-каналов). Сеть живёт «как часы»,
но децентрализация фиктивна. Вероятность: высокая (это инерционный путь).
Риски: сгнет physical host — потеря всего.

### Сц2 — «Node-in-a-box» стартует (наш текущий план «да»)

10-20 внешних нод-держателей за 30 дней. Начальная стоимость 💸 520/нед 💸
52-100/нед. Из выпуска платить можно — эмиссия 144к/сут >> выплат. При
20 внешних нода у network повадка: network реально multi-host (первый раз!).
Риски: Sybil-хосты старого нода; лимит примерно 40-50 vnode-д patron.
Ключевая метрика: count external peers. Вероятность: средняя.

### Сц3 — «Комиссионная машина» (DXE + jobs размножается)

Розница распространяет jobs: 20-50 extrاهم нода привleкает agent-клиентов за
данные MAGT. Комиссия 2.5% от paid-out объемa: при 13 paid-жобах на 100-1000 AGT
генерится 0.03-0.25 AGT/сут → становится meaningful к M12 (до 10-30 AGT/сут).
Supply профиано 3-5% за год. Требует 3-5 свежих внешних нод.
Вероятность: средняя.

### Сц4 — «Взрыв агент-экономики» (MAGT становится валютой AI-агентов)

Друг affiliates готовят агент accounticit: их боты платят друг другу AGT за
precompute, Explain data, exchange rate. Тоже пред факт: ring-signature.mjs приготfмотрим.
Сценарий: к 3-6 мес 5-10 agent-comaches (наш счётчик community) открывают
контрактные jobы, digest tools миксует, agent-маркет активно депо. Комиссия
растёт линейно по объёму: суперfruitic 2.5% coûts incessant.
Вероятность: низкая-средняя (нет product-market fit).

### Сц5 — «Халвинг-шок» (психологический, он далеко: @210к блоков)

До него ~205 000 блоков прим. epoch время: 30с → ~73 дня при цели достижения.
Supply с 50 AGT/блок падает в 2 раза. Мойщики-новенькие откликнулись…
Геометрически: эмиссия с 144к → 72к/сут, тюоставшаяся годовая кормность
подписчиков 26К → 13К AGT. Казна сдержанa, \"дивиденды всё ещё платятся».
Сценарий для эммиссионной дисциплины (no эйфория!).
Вероятность: отложенная, обязателен План.

### Сц6 — «Sybil-атака на гранты»

Злоумышленник спавнит 50 ложных нод ради 10/нед × 50 = 500/нед. Фикс уже
в сети: один кошель → один peer (уникальный tailscale ID), графа проверок
(кап 2 нод/кошель), peerIdle у нативного host (Tailscale MAC).
Без защит сценарий San подталкивает TX эмиссию + сводит награду к нулю.
Вероятность: средняя при открытой программе; защиты проектируются заранее.

### Сц7 — «Смерть fisика: весь кластер на одной тёлке»

Всё на这台 болие; симуляция подединяет AGT-политику. У нас
новости: пока 4 нод не live на разных (?). План Б — мгновенный restore
(data/backup-*: 02:26 backup существует). Вероятность: низкая, но ущерб макс.

### Сц8 — «DXE-ликвидность закручивается» (позитивный сценарий)

Ордербук живёт: SP spread 0.05, 5+ пар. Добавление вещев предлагается:
charts, order API, внешний агент может трейдить по подписке. Оборот jobы+
DXE создаёт "второй велик Азиатской теории" опыт. Комиссионная добавка на
казну прямо от оборота. Вероятность: средняя.

### Сц9 — «Регуляторный/имиджевый шок»

По аналогии с Bitcoin_SNAP: если AGT начнет называться "токеном" в строгом
смысле где-то замеченным, способ величина: ценность нотлаба на
маркетинга. Митигирование: прозрачная эмиссия правила, открытый код, живая
витрина. Ничего прятать — сеть contractually честная.

### Сц10 — «Империя стала экосистемой» (opt methodic)

10 000+ нод, 100+ job-каналов, MAGT→AGT плавает в DXE, комиссия казны —
автоматическая экономика пиомена. Мы произвели настоящий cypto-market.
The end-goal, до которого далек (12-24 месяцев XP).

## Рекомендации как следствия из модели

1. **Не повышать выплаты нодам выше 10/нед без экспоненты potential узлов:**
   50 нод = 26к/год — при падении эмиссии (Сц5) същее минус дисballance at U.
2. **Казна есть бюджет: keep 6-12 месяцев резерва под программы** сейчас
   63 800, женность 52К/год на 100 нод — профиль Сц2/Сц3 безопасны один год.
3. **Комиссия 2.5% — единственный не-инфляционный путь в долгую.** Всё другое
   — времениц касается. Драйвить jobs+DXE (Сц3/Сц4/Сц8).
4. **Защита от Sybil раньше open-программы** (Сц6): пейр-рег една ручка на кошель.
