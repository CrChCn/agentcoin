# Sepolia-пилот моста (подготовка, п.5; развёртывание — отдельной контрольной точкой)

Статус: НЕ РАЗВЁРНУТ. Основная сеть, реальные AGT и ликвидность — НЕ подключать.
Входной порог: пп.1–4 закрыты (все тесты RUNBOOK зелены + независимый отчёт без расхождений-блокеров).

## 1. Отдельная тестовая цепь Agentcoin
- Изолированный дата-директорий и отдельный network-magic/порт; сид-книга пилота ≠ mainnet.
- Vault пилота — новый тестовый адрес; mainnet-vault и казначейские ключи не используются.
- Финализация для mint: K подтверждений Agentcoin (значение фиксируется в журнале развёртывания).

## 2. Только тестовые активы и ключи
- wAGT пилота — новый контракт WrappedAGT (один), шлюз — один BridgeGateway (неизменяемый, без прокси).
- Подписанты федерации: отдельные тестовые ECDSA+ed25519 ключи (N=5, порог — в журнале; рекомендовано 3-of-5).
- Газ EVM: отдельный тестовый ключ с минимальным балансом; ключи оператора vault — офлайн.
- Продовые ключи в пилот не копировать; секреты — вне репозитория/логов/API.

## 3. Малые лимиты (значения фиксируются при развёртывании)
- `maxMintPerOp`: малое (например ≤ 10 wAGT в единицах wei).
- `windowVolumeCap` (24ч) и `netOutstandingCap`: малые, с запасом ниже тестового баланса vault.
- Лимиты меняются только `setLimits` (admin) и фиксируются в журнале.

## 4. Мониторинг, сверка, пауза
- Наблюдатели обеих сетей + `observeLocks`/`computeReserves` по согласованным КТ (checkpoint обеих сетей в каждом прогоне).
- `/bridge/health`: `policyMatch && reconcileOk && evmFinalized && agentcoinTipFresh`, иначе STOP (см. `bridge-halt-stop`).
- Пауза проверена заранее: `setMintPaused(true)` ролью PAUSER останавливает только выпуск; получателей не меняет, средства не конфискует.
- Дефицит после mint: процедура `detectPostMintDeficit.settlement` (инвентаризация → ручное урегулирование → запись → снятие стопа вручную). Авторезюм запрещён.
- Дрилл паузы на пилоте: вызвать паузу, убедиться в `MintPaused` на новом mint, снять только после сверки.

## 5. Журнал развёртывания (заполняется в отдельной контрольной точке)
- Адреса: wAGT, BridgeGateway, admin, pauser, подписанты (EVM), vault Agentcoin.
- Параметры: threshold, maxMintPerOp, windowVolumeCap, netOutstandingCap, agentcoinChainId, dstChainId, PROTOCOL_VERSION/BRIDGE_ID.
- Версии: solc, OZ, hardhat, коммит репо.
- Транзакции: deploy wAGT, deploy gateway, grantRole, propose/applySigners (если были), setLimits, тестовые mint/burn.
- Без этого журнала пилот не признаётся готовым.
