Карта: что от чего зависит

Стрелки: нода ходит наружу только в эти точки. Консенсус (PoW, балансы, agt-verify) — локальный, без внешних ключей.

1. Лицо сети критично

Прод-домены: https://agentcoin.work, https://node1.agentcoin.work
Caddy (прод): маршруты /create-wallet, /live, /wasm/* из agentcoin/caddy-routes.conf — конфиг и root только на прод-сервере, сюда пути не выносим.
Прокси-заголовки = 403 для админки (AGIP-37): x-forwarded-for, x-real-ip, cf-connecting-ip, forwarded, x-via — cloudflared/nginx/Tailscale Funnel перед нодой меняют только вход, не консенсус
Комментарий: упадёт Caddy/443 — витрина мертва, ноды на 933x живы. CORS пускает только *.agentcoin.work.

3. Celestia DA — архив memo высоко для истории

Сеть: mocha-5 namespace 0x61676e61 («agna»)
Прод: mocha-5 + blob.Submit — лайт-нода стоит только на прод-сервере, локальные пути/RPC сюда не выносим.
Логика: scripts/prune-memos.mjs — memo ≥64Б вне окна 1000 блоков → DAA|<sha16>. Генезис-пример на проде DAA|a6d72baa3db900b0 — sha сходится.
Что сломается: нет лайт-ноды — пруны падают, старые memo не восстановить; tip и PoW не страдают.

4. Filecoin — память агентов средне

Скрипты: test_filecoin.py + filecoin/sdk/upload.mjs (Synapse SDK), Warm Storage, calibration testnet
Деньги теста: tFIL (газ) + tUSDFC (хранение), faucet faucet.reiers.io — бесплатно
Ключ кошелька: filecoin/sdk/wallet.json (gitignored — значение сюда не вставляем)
Комментарий: в цепи только memory_cid профиля. Нет Filecoin — не пишется память, деньги/блоки целы.

5. AI средне

Прод: внешних OpenAI/Anthropic-ключей в коде нет. AI живёт только на прод-сервере, локальные адреса/порты сюда не выносим. Без AI assistant отвечает assistant_unavailable.
