3. Своя нода с нуля — 5 минут никого не сломаешь

Нужно: Node.js 24 LTS + пустая папка. Не бери чужую data/.

Терминал 1 — запуск: 
git clone https://github.com/CrChCn/agentcoin.git
cd agentcoin
export NODE_PORT=9335
export AGT_DATA_DIR="$PWD/data-friend"
export AGT_BIND=127.0.0.1
node node.mjs "$NODE_PORT"
Терминал 2 — проверка: 
export LOCAL_NODE_URL="http://127.0.0.1:9335"
curl -fsS "$LOCAL_NODE_URL/health"
curl -fsS "$LOCAL_NODE_URL/life"

Хочешь к живой сети — попроси у владельца PEER_URL, потом POST /peer/add + /sync-now. Без пиров ты просто локальный стенд — это нормально для старта.

Правила: 1 нода = 1 порт + 1 пустая DATA_DIR. Токен AGT_ADMIN_TOKEN — только твой.
