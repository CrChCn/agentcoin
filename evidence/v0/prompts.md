# v0-промпты редизайна AGENTCOIN (с требованием языка по дополнению к ТЗ)

## Промпт 1 — биржа MBC-20 (AC-4)
```
Создай React-страницу для биржи MBC-20. Темная тема, золотые акценты.
Язык: RU. Все тексты интерфейса строго на русском, ни одного английского
слова (кроме технических терминов: API, ticker, txid, memo). Вся локализация
через словарь i18n, переключатель RU/EN в шапке, выбор хранить в localStorage.
Компоненты:
- Стакан (bid/ask) с ценами и объемами.
- График цены (24 часа) с помощью Recharts.
- Список последних сделок (таблица).
- Кнопка "Создать ордер" (если API позволяет) или "В разработке".
Используй Tailwind CSS, TanStack Query.
Данные: GET /dxe/orders (стакан), GET /dxe/items (пары), GET /dxe/fills (лента).
Если API не отвечает — показать ошибку и retry, не падать.
```

## Промпт 2 — главная страница (AC-5)
```
Создай главную страницу AGENTCOIN (темная тема, золотые акценты).
Язык: RU. Все тексты интерфейса строго на русском, ни одного английского
слова (кроме технических терминов: API, WASM). Вся локализация через i18n,
переключатель RU/EN в шапке, выбор хранить в localStorage.
Компоненты:
- Статус сети: высота блока, мемпул, казна.
- Живая лента (последние 20 событий).
- Карта нод (3D-сфера или созвездие).
- Кнопки: "Стать агентом" (WASM), "Майнинг" (/mine), "Задачи" (/jobs), "Биржа" (/mbc20).
- Блок "Экономика": распределение AGT.
Данные: GET /stats-data, GET /blocks?n=20, GET /life, GET /api/v1/mempool,
GET /network/nodes. Если API не отвечает — показать ошибку и retry, не падать.
```

## Проверка языков после генерации (дополнение п.1)
Freebuff проверяет: при RU — ни одного английского слова в UI (кроме
технических терминов), при EN — ни одного русского. При смешении — повторный
запрос в v0 с уточнением, либо ручная правка.
