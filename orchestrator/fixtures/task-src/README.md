# Fixture: pricing task

Учебная фикстура для сквозного теста оркестратора. Не содержит бизнес-логики
Agentcoin и не обращается к сети, нодам, очереди или деньгам.

- `src/pricing.mjs` — скелет, который реализует исполнитель.
- `tests/acceptance.test.mjs` — приёмка задания; проверяющий запускает её в
  своём чистом клоне базового коммита.
- проверяющий дополнительно устанавливает свои граничные тесты
  (`fixtures/reviewer-checks/reviewer.extra.test.mjs`), которых нет у исполнителя.

Известный дефект первой итерации: строгая граница бесплатной доставки
(`>` вместо `>=`), поэтому заказ ровно на 5000 центов ошибочно считается
платным. Приёмка AC-5 это ловит.
