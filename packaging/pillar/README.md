# Pillar — независимый столп сети Agentcoin

Принцип как у Bitcoin: **кто держит ноду — тот и майнит**. Pillar — это обычная
`node.mjs`, но обёрнутая так, чтобы столпом мог стать любой друг, а не только
оператор с сервером.

## Чем столп отличается от portable 0.1.0

| Portable 0.1.0 | Pillar |
|---|---|
| `AGT_BIND=127.0.0.1`, только pull с сида | бинд `0.0.0.0` по умолчанию — принимает **входящие** соединения |
| Майнинг вручную через `POST /mine` | Майнинг **встроен и включён**: кошелёк создаётся сам, блок каждые ~60с на свой адрес |
| Никому о себе не говорит | Анонсирует свой `PUBLIC_URL` сидам (`POST /peer/add`), тянет `/sync-now` по кругу |
| Данные в `data/` | Данные в `data-pillar/` (кошелёк, токен, цепь — рядом, не в коде) |

Консенсус не тронут: та же `core.mjs`-сложность (12–20 бит, ретаргет каждые N
блоков, интервал ~30с), та же валидация. Децентрализация — от независимых
операторов, а не от новой цепи.

## Запуск (5 минут)

```bash
node packaging/pillar/pillar.mjs --port 9335
# или двойным кликом: start-pillar.cmd (win) / start-pillar.sh (linux/mac)
```

Первый запуск создаст `data-pillar/pillar-miner-wallet.json` (адрес + приватный
ключ, `0600`) и `data-pillar/pillar-admin-token.txt`. Никому их не отдавай.

Проверка: `curl http://127.0.0.1:9335/life` — высота растёт и догоняет сеть.

Первый запуск догоняет ~3–4 тысячи блоков и в это время нода может не отвечать
на `/life` (event loop занят проверкой) — это нормально и честно показывается
в логе как «догоняет сеть — майнинг на паузе». Майнинг стартует сам, только
когда tip свежий (`fresh=true`): майнить на протухшем tip запрещено правилом
AGIP-7, иначе столп закрепил бы собственный форк.

## Как стать НАСТОЯЩИМ столпом (обязательное условие)

Без этого будешь «майнящей копией за NAT» (тоже полезно, но не столп):

1. Пробрось порт наружу (роутер → твой ПК: `9335 → 9335`, или сервер с белым IP).
2. Задай свой публичный адрес:
   `node packaging/pillar/pillar.mjs --public http://ТВОЙ-БЕЛЫЙ-IP:9335`
3. Открой порт в файрволе + держи машину онлайн 24/7.

Тогда сиды примут твой анонс, чужие ноды начнут ходить к тебе за `/headers` и
`/blocks`, а твои блоки — расходиться по сети. Это и есть столп.

## Чего столп НЕ делает

- Не колдует с NAT/UPnP: если проброса нет — честно пишет
  «без анонса», а не притворяется столпом.
- Не хранит чужие ключи: майнит только на свой локальный кошелёк.
- Не открывает админку миру: публичный бинд только в token-режиме,
  токен — в `data-pillar/pillar-admin-token.txt` (`0600`), пиру не передаётся.
- Не форкает экономику: награда и сложность — из общей `core.mjs`.

## Режимы

- Столп: `--bind 0.0.0.0 --public http://IP:9335` (нужны белый IP/проброс).
- Тихая копия: `--bind 127.0.0.1` (без `--public`) — майнит себе, тянет сеть.
- Только нода: `--no-mine` — без майнинга.
- Свой сид-лист: `--seeds https://agentcoin.work,http://друг:9335`.
