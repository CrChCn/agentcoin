## Причина раздвоения `/` (сохранено до исправления)
- Сервер: `handle @agtEmpireRoot (path /)` → `rewrite /imperial.html` (200, Imperial).
- Клиент: `web/out/mine.html` (Next SPA) содержит `next/link href="/"` → клик «Сайт»
  выполняет client-side переход на Next-главную без запроса к серверу (URL `/`,
  тело — Next home). Обновление → сервер снова отдаёт imperial. Доказательства:
  `REPRO_URLS.txt`, sha `/`=f12aed…, `/mine`=eaf3e6…, `/robots.txt`=200 text/html-лендинг.
- Исправление: шапка и `page.jsx` переведены на обычные `<a>` (полная серверная
  навигация); `/index` → редирект на `/`; catch-all `try_files … /index.html`
  заменён на настоящий 404; `robots.txt`/`sitemap.xml` — реальные файлы.

## API и авторизация (§8, реестр — срез, полный список — в коде ноды)
- Публичные чтения — через allowlist Caddy (`@public_reads`, `@api_allowlist`):
  `/info /health /stats /blocks /headers /balances /balance /capabilities /jobs/state /gov/state /network/nodes /mbc20/* /dxe/* …` → `127.0.0.1:29335` / нода. Auth: нет. Побочек нет. Повтор: безопасен.
- Записи (`@node_writes`: `/tx /balance /tx/preflight /cabinet/* /identity/* /gate/* /block/submit /peers/announce …`) → `node1.agentcoin.work` (sticky, паспорта в памяти). Auth: подпись/сессия; админ-пути — `x-admin-token` (нода проверяет, браузеру не выдавать).
- `/pool/join`, `/pool/submit` (`submit` в `@node_writes`): приём шар закрыт — страница честно показывает 405. Открытие — только словом владельца (деньги сети). Не «чинить» allowlist без доступного upstream — зафиксировано.
- `/queue/* /agent-state /catalog/* /orders/* /events /mainnet/*`: сверить с capabilities; расхождение capabilities↔факт — дефект до закрытия. Админ-защита ноды не отключается; админ-токен в браузер не передаётся.
- Режим подписанных действий: зафиксировать реальный (что уже переведено на подписи — одновременно обновить UI+SDK+MCP+доки; что нет — явно пометить как стенд-режим, не выдавать за прод).

## Деньги и заказы (§10), метрики (§11), события (§12), интерфейс (§13)
- Путь заказ→обязательство→политика→подпись→txid→подтверждение→обновление UI — только изолированными пробами, без массовых нажатий на mainnet. TEST-книга в прод-расчётах не участвует (проверка guard №10).
- Метрики с единым определением (источник/формула/единицы/давность): намайнено, казна, баланс, выплаты, очередь, назначения, паспорта, ноды/пиры. Казну между главными привести к одному правилу (дефект зафиксирован). Запрещены: 0 вместо ошибки; число endpoint вместо операторов; очередь адресов как «ИИ-процессы»; анимация как доказательство; время ответа как время данных.
- События: `eventId/eventType/entityId/entityVersion/operationId/correlationId/occurredAt/observedAt/source/network/visibility/evidence`; «очередь непуста vs сфера пуста» — развести ошибку получения и корректный пустой снимок; рестарт/реконнект/дедуп — проверить.
- Единый интерфейс: шапка/хлебные крошки/язык/тема/кнопки/форматы AGT-времени-адресов/загрузка-stale-ошибка/мобильная навигация/фокус/reduced-motion. Двойники не перекрашивать.
