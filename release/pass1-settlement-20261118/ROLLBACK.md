# Откат релиза прохода 1

## Процедура (только с явного слова владельца)
1. Сохранить копию текущего журнала: `mainnet-settlements.json` (путь из юнита
   `agt-settlement`) — журнал назад НЕ откатывать ни при каких условиях
   (иначе возможны двойные выплаты: повтор обязан слать ТЕ ЖЕ байты).
2. Остановить юнит: `systemctl stop agt-settlement`.
3. Восстановить файлы предыдущего комплекта из его каталога `release/*`
   (проверка: `sha256sum -c SHA256SUMS` внутри того каталога).
   ЗАПРЕЩЁН общий `git checkout` рабочего дерева — он может уничтожить
   незакоммиченные изменения.
4. `systemctl start agt-settlement`; сверить `/version` и `/mainnet/info`.
5. Caddy-роуты при этом релизе не менялись — `caddy reload` не требуется.

## Что не затрагивается
- Нода, цепь, консенсус (`core.mjs`), данные ноды.
- Журнал платежей (только копия, п. 1).
- Пользователь ноды, offsite-бэкапы — отдельные инфраструктурные работы,
  не смешиваются с этим релизом.
