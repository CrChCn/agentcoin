# Проход 3 — модерация страниц: workspace, mine, mbc20, docs (2026-11-18)

Опубликовано: https://agentcoin.work/ (поверх прохода 2, нода/консенсус не тронуты).
Целостность: `sha256sum -c SHA256SUMS` из этого каталога (`out/` — собранный
`web/out`, побайтово сверен с продом по ключевым страницам до деплоя).

## Что исправлено
- `/workspace` (был: 200 с чужим лендингом) — новый read-only инспектор рабочей
  цепи в стандартном дизайне: цепь / очередь / джобборд / паспорта / пул + ссылки.
  Только GET существующих API (`/api/v1/info`, `/queue/status`, `/jobs/state`,
  `/passport/count`, raw `/pool/stats`). Подпись/регистрация — на ноде оператора.
- `/mine` — убрана ложная инструкция (`git clone github… + cargo run`, гитхаба нет,
  127.0.0.1 доступен только с сервера). Честно: соло — только нода оператора;
  внешний приём шар (`POST /pool/join|/submit`) закрыт (405) — страница так и пишет,
  приём откроется только решением владельца. Добавлена живая карточка пула
  (raw `/pool/stats`). Исправлена ложь «ретаргет каждые 2016 блоков» → каждые 10.
- `/mbc20` — баланс принимал только голые 40 hex и отвергал канонические адреса
  (`AGT…` — «Ошибка: адрес должен быть 40 hex»). Теперь `web/lib/addr.js`:
  принимает с префиксом/без, возвращает канон `AGT+40hex`. Токены — с живого
  `/api/v1/mbc20/state` (было: несуществующий `/api/v1/mbc20/tokens` → вечное «—»).
  Фейковая «Эмиссия токена» (`/api/v1/mbc20/deploy` → 404) заменена честным
  «Стаканом» (`/api/v1/mbc20/book?tick=`).
- Та же нормализация адресов — на `/agent` (та же ошибка с AGT-адресами).
- `/docs` — ссылки вели на голые .md (белая страница, чёрный текст). Теперь ведут
  в `/docs/view?f=` — тот же побайтово текст в дизайне сайта (лёгкий рендер без
  зависимостей, белый список 8 файлов). Сырцы `/docs/*.md` для curl/агентов — без
  изменений. В список добавлен `WHAT-IS-AGT.md`; `site/docs/` доукомплектован
  с прода (4 файла).
- Текст `err.addr` (ru/en): «нужен адрес AGT + 40 hex».
- `site/tree.json`: + `/workspace` в раздел engine (канон сохранён).

## Маршрутизация (Caddy, validate OK + reload, рестарта ноды не было)
