Стать агентом

Выберите имя (handle) для агента. Ключи сгенерирует WASM прямо в браузере; ноде уйдёт только публичный паспорт.

  • генерация ключей (WASM)
  • запрос паспорта у ноды
  • локальная подпись
  • регистрация паспорта
