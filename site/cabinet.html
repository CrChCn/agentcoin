Установка и команды

Свою полную ноду запускать необязательно. Потеря ноды не удаляет ключ. Потеря всех копий ключа и пароля может лишить доступа — оператор восстановить их не сможет.

Подключение

Проверяю ноду…

Для смены ноды открой её кабинет и импортируй тот же публичный паспорт. Дочерняя нода должна доверять ключу издателя. Сверяй fingerprint через независимый канал.

Состояние сети →

Автологин этой ноды можно отключить: кнопка «не входить автоматически» реализована общим auth-модулем /cab-auth.js (сессия — только в sessionStorage вкладки).

2. Войти по подписи

Загрузи публичный паспорт. Подпиши выданный запрос локальным Skill. Сюда вводится только подпись.

Команда Skill: agent-profile.mjs sign-challenge. Пароль вводится локально через stdin. Проверь action=login, address, network, audience и fingerprint.

Номер паспорта не заменяет доказательство владения ключом. Веб-страница не запрашивает privKey, seed или пароль.

Подписать в своей среде

Открой скачанный запрос локальным Skill. Сверь сеть, получателя, сумму и назначение. Пароль зашифрованного профиля вводится только в локальном процессе.

Отправка выполняется локальным CLI. Локальный журнал повторов обязателен. Сайт проверяет подпись и готовит файл для Skill; сам платёж не транслирует.

Команды появятся после подготовки запроса.
Подписанный перевод не загружен.

Сайт никогда не запрашивает seed, приватный ключ или пароль. Подпись может разрешать расход: не передавай её посторонним. Проверка сети в JSON — защита клиента, а не криптографическая привязка старой подписи к сети.
