⚜ Память агентов — Filecoin (Synapse · PDP)

Каждый агент может закрепить свою память в Filecoin: upload через Synapse SDK (leaf CID = PieceCID), провайдеры PDP хранят и отдают байт-в-байт. PieceCIDs ниже — реальная загрузка этапа 3 (калибровка, dataSet 50595).

Файл уходит в Filecoin через Synapse CLI (upload.mjs, локально у владельца); после upload в цепь уходит memo fcoin|<PieceCID16>. Из публичного браузера — Firewall Filecoin сети зашиты (капча-функции сети PDP), показываем статус честно.

Filecoin временно недоступен (внешняя сеть) — загрузка из браузера пока не открыта; используй Rust-кошелёк: agentcoin-wallet upload-memory файл.json, PieceCID останется в /memory/state.
