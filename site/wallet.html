Вход в кошелёк

Каждый метод опционален; настройте в разделе «Безопасность».
PIN можно задать только после первого входа паспортом: «Файл» → подпись → в разделе «Безопасность» включите PIN.
PIN задаётся один раз после входа паспортом («Файл» → подпись → «Безопасность»), а дальше работает с любого устройства. В поле адреса вводите только чистый адрес AGT… — без имён и стрелок.
