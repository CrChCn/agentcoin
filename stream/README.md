# Стрим-кит «Император Сети»

Эфир о сети AGENTCOIN: оверлей с живыми данными ноды, телесуфлёр с русской озвучкой,
сцена OBS одним файлом и пульт эпизода, который нанимает агента через эскроу и
выдаёт проверяемую карточку с txid и merkle-пруфом.

```
stream/
  server.mjs          локальный сервер (только 127.0.0.1) + read-only прокси к ноде
  overlay.html        1920×1080: ?bg=1 — тёмный холст, без параметра — прозрачный
  avatar-emperor.jpg  аватар Императора, вшит в оверлей
  obs-scene.json      сцена OBS одним файлом: оверлей + микрофон + Chrome TTS
  teleprompter.html   суфлёр + озвучка (Web Speech, ru-RU)
  episode-01.json     сценарий пилота — единственный источник реплик
  episode.mjs         эскроу → выплата → карточка эпизода
  crew.json           труппа: кто ведёт смену, ставка, адрес
  episodes/           карточки эпизодов (json + md), создаются episode.mjs
  emperor.md          библия персонажа
  episode-01.md       человекочитаемый сценарий
  studio-prompt.txt   промпт для создания канала в AITV Studio
  shots/              контрольные скриншоты вёрстки
```

## Запуск

```bash
node stream/server.mjs
# оверлей:      http://127.0.0.1:8790/overlay.html?bg=1
# телесуфлёр:   http://127.0.0.1:8790/teleprompter.html
```

Сервер слушает только loopback. Нода по умолчанию `https://node1.agentcoin.work`
(`AGT_NODE_URL`), порт — `AGT_STREAM_PORT`. Прокси отдаёт только `/life`, `/info`,
`/escrow/state`, `/txproof/<txid>` — открытого релея нет.

## Сцена OBS

`stream/obs-scene.json` → **Scene Collection → Import** (OBS 30+), либо скопировать в
`%APPDATA%\obs-studio\basic\scenes\`.

- **ЭФИР 1920×1080** — `overlay.html?bg=1`, `Микрофон` (устройство по умолчанию),
  `Chrome — TTS` (захват звука приложения), `Системный звук (резерв)` выключен.
- **ПРОЗРАЧНЫЙ ОВЕРЛЕЙ** — тот же оверлей без фона, для композа поверх камеры.

В свойствах `Chrome — TTS` выбери окно Chrome с вкладкой «Император Сети — телесуфлёр».
Если список пуст — включи «Системный звук (резерв)» и выключи Chrome-захват.
Сцена собрана без отдельного фона: тёмный холст рисует сам оверлей (`?bg=1`), поэтому
порядок слоёв в OBS не может «уронить» картинку.

Вручную, если нужна своя раскладка: браузер-источник 1920×1080 с «Обновлять при
активации», захват звука приложения Chrome, микрофон; центр кадра свободен под
камеру/скринкаст. Вывод — 4500–6000 kbps для 1080p30.

Суфлёр: `→` / `←` листать, `Пробел` озвучить, `A` автоплей, `Esc` стоп.

## Пульт эпизода

Смена агента = обычный эскроу сети. Платим за принятую работу, а не за «активность».

```bash
node stream/episode.mjs roster
node stream/episode.mjs hire --agent Летописец --task "Смена: цифры сети и выплата с пруфом"
node stream/episode.mjs status --escrow <escId>
node stream/episode.mjs pay --escrow <escId>
node stream/episode.mjs card --escrow <escId>          # txid + merkle + PoW
node stream/episode.mjs card --escrow <escId> --api https://node1.agentcoin.work
```

- `hire`/`pay` пишут только на **локальную** ноду: `/escrow/create`, `/claim`, `/payout`
  подписывают ключами из data-каталога ноды. Скрипт ключи не читает и не печатает.
  Снаружи нужен SSH-туннель до `127.0.0.1:9335`.
- `card` — только чтение, работает против любой ноды. Пересчитывает ветку Меркла,
  хеш блока и PoW **у себя** и пишет `episodes/<escId>.{json,md}`.
- `--dry-run` показывает тело запроса, ничего не отправляя.

Работодатель по умолчанию — казна (`crew.json → employer`). Казна 2-of-3: одиночная
подпись в `/escrow/create` не пройдёт, для эфира проще отдельный кошелёк одной подписью
(`--employer AGT…`). Агент должен быть кошельком на той ноде, где идёт выплата, иначе
`claim` нечем подписать.

## AITV Studio

`aitv.gg/studio` → Create a Channel: канал создаётся промптом (`studio-prompt.txt`),
дальше аватар, голос, расписание, мультистрим в Twitch/YouTube/TikTok/Kick/X.
Монетизация — кредиты зрителей (20% сетевой сбор → выкуп $AITV), для выплат нужен
подключённый кошелёк. Studio в бете, есть waitlist. Канал и кошелёк создаются тобой:
это твой аккаунт и твоя подпись.

Порядок: сначала локальный стек + Twitch/YouTube, AITV — четвёртым рестримом.

## Ограничения, честно

- Я не выхожу в кадр и не говорю своим голосом: озвучка — системный TTS (Microsoft Irina
  в Chromium). Для эфира можно заменить на ElevenLabs, текст тот же.
- Стрим-машина и OBS работают на твоём компьютере; в чате я не нахожусь в эфире.
- Если нода недоступна, оверлей краснеет и держит последние цифры — выдуманных значений нет.
- Выплаты в эфире — реальные AGT; сумму и агента готовим до эфира.
