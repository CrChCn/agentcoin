## Сбои релейера (все — на итоговом SHA, стенд accept:v2)

Инвариант: один депозит — один выпуск, один burn — один возврат.
Рубежи: файловый журнал intent + on-chain `mintedDeposit` (`deposit_replayed`).

| Кейс | Сбой | Состояние до/после рестарта | Итог |
|---|---|---|---|
| Ma | intent записан, сбой до отправки mint | журнал: intent→minted; supply +1 ровно один раз | ровно один выпуск |
| Mb | mint-tx в мемпуле (receipt null), сбой до записи | висящая tx подтверждена как есть (`mempool-mined-no-resend`), второй отправки нет | без дубля |
| Mc | mint-tx в блоке, сбой до записи | сверка нашла mint (`already-minted`), supply не изменился | без дубля |
| Md | lock исчез из цепи | mint НЕТ; halt `lock_event_vanished`; сброс только вручную | направление стоит |
| Ea | intent зрелого burn, сбой до выплаты | журнал: intent→released→confirmed; ровно одна выплата 1 AGT | одна выплата |
| Eb | выплата в мемпуле AGT, сбой до записи | висящая выплата подтверждена как есть, второй нет | без дубля |
| Ec | выплата в блоке, сбой до записи | сверка нашла выплату, повтора нет (баланс +0) | без дубля |
| Ed | подтверждённый burn стёрт реоргом после порога | `burn_event_vanished` + halt; новые выплаты стоят; сброс вручную → burn пересоздан → порог → выплата 1 AGT | остановка+возобновление |
| Ee | выплата ни в цепи, ни в мемпуле | новой выплаты НЕТ (`release_fate_unknown` + halt), решает оператор | без дубля |

Свидетельства (журнал до/после, обе цепи, txid) — в `accept-v2-report.json`
(`mintCrashes`, `releaseCrashes`). Примеры: burn Ed `0x4f05f9b6…`,
выплата Eb `9bafc82c…` (была в мемпуле), burn Ee `0x67e8db9f…` (без выплаты).

## Резерв

- Формула: `vault − Σоткрытых выплат − Σсожжённых-без-выплаты == supply + Σоткрытых mint`.
- Финал стенда: **vault=42, supply=41**, сожжён-без-выплаты (Ee, по решению
  оператора) = 1, открытых нет → **41 == 41, сошёлся**.
- Искусственное расхождение (прямой перевод из vault без burn): обнаружено,
  контракт на паузе + halt обоих направлений; возобновление только оператором
  после разбора (докапитализация → ручной сброс с причиной → unpause →
  контрольный mint). Кто/по каким данным: `BRIDGE-OPS.md` §6–7.
- Пыль wAGT < 1 не сжигается/не возвращается (AGT целочисленный).
