## 2. Ликвидность

| Параметр | Предложение |
|---|---|
| Объём | **10 000 wAGT + 100 000 USDC**, стартовое соотношение **1 wAGT = 10 USDC** |
| Backing | 10 000 AGT блокируются в vault ДО пополнения пула; сверка `vault == supply` — обязательное условие |
| Газовый бюджет | **0.05 ETH** на операционном кошельке (факт Sepolia-цикла ~0.0408 ETH; создание пары — самая дорогая операция) |
| Владелец LP-позиции | мультисиг владельца (деплой и первичное внесение — согласованный EOA, затем LP-токены переводятся на мультисиг) |
| Снятие ликвидности | только подписью мультисига; частичное — решением владельца |

## 3. Резерв и полномочия

| Роль | Предложение (держатель) | Полномочия / смена |
|---|---|---|
| owner контракта | мультисиг владельца | `setMinter`, `setPauser`; смена — самим мультисигом |
| pauser | дежурный мультисиг (2 адреса операторов) | `pause`/`unpause` немедленно по алерту; снятие — только после разбора с подписью owner |
| minter (релейер) | hot-ключ релейера | только `mint`; ротация — `setMinter` по подписи owner, старый ключ умирает сразу (стенд R4) |
| хранитель vault AGT | мультисиг владельца (= owner) | `release`; ротация — процедура мультисига |
| оператор релейера | дежурный | ворота/halt по `BRIDGE-OPS.md`; ключей моста нет |

Адрес vault публикуется в день запуска (вывод `lock`-адреса + первая сверка).

## 6. Как проверяется (после каждого шага)

- **Байткод**: `solc 0.8.24`, sources = `contracts/WAGTv2.sol` + `@openzeppelin/contracts 5.x`
  (как `hardhat.config.cjs` стенда); сравнить `eth_getCode(wAGT)` с локальным
  артефактом (metadata-хвост отбросить); плюс verify на Etherscan.
- **Адрес пула**: `Factory.getPair(wAGT, USDC)` после шага 7 + независимый
  CREATE2-расчёт (init code hash V2 pair) — должны совпасть.
- **Адреса токенов**: wAGT — квитанция деплоя; USDC — константа выше
  (сверить decimals=6 on-chain).
- **Ссылка**: открыть оба направления, сравнить цену пула с `getReserves`.

## 7. Известные принятые риски

- Обеспечение — vault-контроль, а не ончейн-пег: ключ хранителя = мультисиг.
- USDC замораживаемый (Circle blacklist): риск принятого контр-токена.
- Пауза доверяет pauser; снятие — только после разбора owner-мультисигом.
- Пыль wAGT < 1 не возвращается (AGT целочисленный) — остаётся у пользователя.
