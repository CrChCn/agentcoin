# ТЗ для Codebuff — тестовый обмен wAGT через Uniswap V2 на Sepolia

## 0. Цель

Провести полный цикл через **официальные контракты Uniswap V2 на публичной тестовой сети Sepolia**:

> заблокировать тестовый AGT → выпустить wAGT → обменять wAGT → сжечь wAGT → вернуть нативный AGT.

Приёмка: обмен подтверждён транзакцией в официальном пуле Uniswap V2 на Sepolia, возврат подтверждён в тестовой цепи Agentcoin, повтор события не создаёт лишний выпуск или выплату. При блокере указать точный шаг и текст ошибки.

Использовать **только тестовые средства**. Основная сеть, реальный резерв и ликвидность — отдельный этап после приёмки.

## 1. Исходная точка

- Каталог: `tools/wagt-cycle/`, коммит `48140c0` (main после PR #15).
- Локальный цикл уже пройден (`npm run cycle`, exit 0). **Сохранить его как быстрый тест** и добавить **отдельный сценарий для Sepolia** (например, `scripts/cycle-sepolia.mjs` + npm-скрипт `cycle:sepolia`), не ломая локальный.
- Технические решения в рамках теста принимать самостоятельно.

## 2. Подготовить тестовую среду

1. Использовать **изолированную ноду Agentcoin со свежим каталогом данных** и **отдельный кошелёк Sepolia**.
2. Перед отправкой транзакций скрипт обязан:
   - проверить `chainId = 11155111`;
   - убедиться, что нода Agentcoin запущена в изолированном тестовом окружении (не прод).
3. Сверить адреса Factory и Router02 с официальной документацией Uniswap:
   - V2 factory `0xF62c03E08ada871A0bEb309762E260a7a6a880E6`;
   - Router02 `0xeE567Fe1712Faf6149d80dA1E6934E354124CfE3`.
4. Через RPC проверить, что по обоим адресам есть код (`eth_getCode` непустой) и что `Router02.factory()` возвращает адрес выбранной Factory.
5. Привести источники в README (документация Uniswap, конфиг Sepolia от EF).
6. Проверить баланс SepoliaETH тестового кошелька и **оценить расход газа до запуска**. Если газа не хватает — сообщить публичный адрес тестового кошелька и сколько не хватает, работу остановить.
7. **Ключи и seed-фразы не включать** в код, логи или отчёт. Ключ передавать только через переменную окружения (например, `SEPOLIA_PRIVATE_KEY`), пример — в `.env.example` без значений.

## 3. Провести полный цикл

1. Развернуть на Sepolia тестовые контракты **wAGT** и **tAGT** (tAGT — тестовый актив для пары).
2. Заблокировать **40 AGT** на изолированной ноде. После подтверждения депозита выпустить **40 wAGT** на адрес поставщика ликвидности.
3. Через официальные контракты Uniswap V2 создать пару wAGT/tAGT и внести **40 wAGT + 400 tAGT**. Получить адрес пары из Factory и проверить фактические резервы.
4. Отдельным депозитом заблокировать **5 AGT** и выпустить **5 wAGT** на адрес трейдера.
5. Обменять **2 wAGT на tAGT через Router02**. Зафиксировать: котировку, минимально допустимый выход (slippage/deadline), фактическую сумму и изменение резервов.
6. Сжечь оставшиеся **3 wAGT** трейдера, привязав запрос возврата к его адресу Agentcoin. После подтверждения сжигания вернуть **3 AGT** из тестового резерва. Проверить зачисление по транзакции Agentcoin.
7. После завершения всех операций сверить: **42 AGT в резерве и totalSupply = 42 wAGT**. Суммы считать в целых минимальных единицах. Газ Sepolia учитывать отдельно (не смешивать с суммами цикла).

## 4. Проверить защиту от повторов и сбоев

| Сценарий | Критерий приёмки |
|---|---|
| Повтор одного депозита | Второй выпуск отклонён. `totalSupply` не изменился. |
| Неподтверждённый депозит | Выпуск не происходит до заданного порога подтверждений. |
| Повтор одного события сжигания | Второй возврат отклонён. В Agentcoin есть ровно одна выплата по этому событию. |
| Перезапуск релейера после отправки возврата | Релейер находит уже отправленную транзакцию и не создаёт вторую выплату, даже если перезапуск произошёл до записи отметки об обработке. |
| Итоговая сверка после перезапуска | Резерв, предложение wAGT и журнал операций сходятся с данными обеих сетей. |

## 5. Сдать результат

1. PR в `main` и команду запуска сценария Sepolia (например, `npm run cycle:sepolia`).
2. В README: параметры окружения, требования к тестовому газу, порядок повторения.
3. Адреса контрактов и пары, ссылки на транзакции Sepolia (выпуск, внесение ликвидности, обмен, сжигание). Приложить полные txid блокировки и возврата AGT.
4. Отчёт по суммам до и после, результаты проверок повторов и перезапуска, фактические комиссии за газ.
5. Открытые вопросы перед основной сетью: кто управляет ключами резерва и правом выпуска, как обрабатываются откаты блоков (reorg), как восстанавливается работа релейера после сбоя. Зафиксировать, что доказал тест и какие сценарии ещё не проверены.

## 6. Границы

- Только Sepolia + изолированная тестовая нода Agentcoin. Никаких операций в основной сети.
- Не коммитить ключи, seed-фразы, `node_modules`, `artifacts`, `cache`, логи.
- Локальный сценарий (`npm run cycle`) должен продолжать работать без Sepolia-зависимостей.
