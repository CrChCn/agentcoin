# wAGT/WETH на Uniswap V2 — предложение партнёру

Короткая карточка: её можно переслать целиком. Все суммы и проценты ниже —
точный расчёт по формуле Uniswap V2 в минимальных единицах (тест
`partner-scenarios.test.mjs`, exit 0). Стартовая цена **0,0005 WETH за wAGT —
допущение**; стороны фиксируют свою цену до запуска. Комиссия пула 0,3%
входит в отклонения; газ сети — отдельно. Пул wAGT/WETH в основной сети
**ещё не запущен**. Доходность не обещается.

## Три варианта глубины (сделка 2 wAGT, допуск 1% в каждую сторону)

| Вариант | Проект: AGT в резерв моста → wAGT в пул | Партнёр: WETH в пул | Продажа 2 wAGT (средняя цена) | Покупка ровно 2 wAGT (средняя цена) |
|---|---|---|---|---|
| A · Пилот | 40 AGT → 40 wAGT | 0,02 WETH | 0,00094966 WETH (0,00047483; 5,03% — мимо) | 0,00105580 WETH (0,00052790; 5,58% — мимо) |
| B · Рабочий | 283 AGT → 283 wAGT | 0,1415 WETH | 0,00099002 WETH (0,00049501; 0,99% — проходит) | 0,00101015 WETH (0,00050507; 1,02% — мимо) |
| C · Минимум в обе стороны | 289 AGT → 289 wAGT | 0,1445 WETH | 0,00099017 WETH (0,00049508; 0,98% — проходит) | 0,00101000 WETH (0,00050500; 1,00% — проходит) |

40 AGT в резерве обеспечивают те же 40 wAGT, которые идут в пул (1:1);
аналогично 283→283 и 289→289. B проходит только продажу: покупка требует
чуть больше глубины (асимметрия округления +1 wei в пользу пула) — отсюда
вариант C. Допуск проверен по точному значению (вниз для продажи, вверх для
покупки), в таблице отклонения округлены до сотых.

## Вклад проекта

- AGT в резерв моста (цепь AGT, вне EVM): 40 / 283 / 289 по варианту.
- Те же wAGT в пул (выпуск мостом 1:1, операциями не более 40 wAGT —
  лимит релейера: A — 1 выпуск, B — 8 выпусков 7×40+3, C — 8 выпусков 7×40+9).
- Операционные подписи стороны проекта: деплой моста, вызовы mint,
  перевод wAGT в совместное хранение, совместные подписи.

## Вклад партнёра

- WETH в пул: 0,02 / 0,1415 / 0,1445 по варианту.
- Отдельный бюджет в ETH на комиссии (свой газ + газ шагов проекта —
  у проекта бюджет 0 ETH; источник газа шагов проекта — открытое решение,
  вариант по умолчанию: операционный адрес проекта пополняет партнёр,
  учёт — по согласованию).

## Кто подписывает и кто платит газ (по шагам)

| Шаг | Подписывает | Газ, оценка |
|---|---|---|
| 1. Деплой моста WAGTv2 (mainnet) | проект (deployer) | 0,9–1,3M |
| 2. Перевод AGT в резерв моста | владелец AGT (цепь AGT, не EVM) | комиссия цепи AGT — проект |
| 3. Выпуск wAGT (mint, ≤40 за операцию) | проект (minter), операций: A — 1, B/C — 8 | 70–90k за операцию |
| 4. Деплой Safe 2-of-2 (владельцы: проект + партнёр) | деплоит один (вариант: партнёр) | 0,3–0,45M |
| 5. Проект → wAGT на Safe; партнёр → WETH на Safe | каждый свою (2 перевода) | ~50–65k каждый |
| 6. Safe: approve + addLiquidity (создаёт пару) | ОБЕ подписи (порог 2-of-2) | ~2,0–2,5M (создание пары — самая тяжёлая часть) |
| 7. Контроль: покупка, продажа, возврат части в AGT | оператор по согласованию (вариант: партнёр) + держатель wAGT для burn | swap ~110–160k каждый; burn ~60–80k |

Источник оценок: исторические вызовы методов UniswapV2Router02 и ERC20 в
mainnet (проверяемо по Etherscan); допущения: стандартные реализации,
без конкуренции за блок. Перед запуском — обязательный `eth_estimateGas`
по факту. Цена газа плавающая: итог в ETH = gas × gasPrice. Пример (не
обязательство): весь пилот ≈ 3,9M газа ≈ 0,0117 ETH при 3 gwei.

## Право на ликвидность

- LP-токены хранятся на Safe 2-of-2 (проект + партнёр); любое внесение или
  вывод — только обеими подписями. Без совместного решения пул не создаётся
  и ликвидность не выводится.
- Доли, распределение комиссий пула 0,3%, условия и сроки выхода — предмет
  согласования (не решены). Доходность не обещается.
