# Agentcoin · тестовая торговля (AGT-DEX-DEMO)

Учебная страница: симулятор пула wAGT/tAGT (резервы 40/400, формула Uniswap V2,
комиссия 0,3%, целые числа в минимальных единицах) + карточка подтверждённого
обмена на Sepolia. Кошелёк не нужен, транзакции не отправляются, бюджет 0 USDC.

## Локальный запуск

```sh
cd tools/wagt-demo
python3 -m http.server 8099
# открыть http://localhost:8099/index.html
```

Любой статический сервер подойдёт (нужен http, а не file://, из-за ES-модулей).

## Проверки

```sh
node tools/wagt-demo/quote.test.mjs   # математика vs контрольный сценарий PR #16
```

- Продажа 2 wAGT из 40/400 даёт ровно `18.993189503262370814` tAGT
  (совпадает с локальным пулом стенда и сделкой Sepolia).
- Покупка в обратную сторону по обновлённым резервам сверена независимым
  расчётом той же формулы (внутри теста — вторая реализация).
- Отказы (ноль/минус/мусор/19 знаков/нехватка баланса) не меняют состояние;
  «Сбросить» возвращает 40/400 и учебный баланс 5 wAGT / 100 tAGT.
- Вёрстка: суммы полной точности, на 390 px читаются целиком внутри карточек.

## Файлы

- `index.html` — страница (два режима: «Симулятор», «Обмен на Sepolia»).
- `math.js` — формула и состояние, без DOM (используется и тестом).
- `ui.js` — привязка к DOM.
- `quote.test.mjs` — проверки симулятора, exit 0.
- `liquidity.js` — математика калькулятора ликвидности wAGT/USDC (18/6 знаков,
  отклонение от номинала, точный минимум резервов; DOM нет).
- `liquidity.test.mjs` — сверка трёх сценариев, покупки/продажи, резервов и
  отказов, exit 0.
- `liq.js` — вкладка «Ликвидность» (калькулятор, сценарии, карточка партнёру).
- `site/` — копия для хостинга предпросмотра (`public/` + `worker.js` +
  `manifest.json`); предпросмотр (preview):
  https://site-1bd656b3193d4ca78813e5003f58b529.freebuff.page
  Отдельный деплой, вне agentcoin.work; production не используется.
