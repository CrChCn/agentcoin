Условия для партнёра (вариант для обсуждения)
  • Газ: каждую транзакцию оплачивает её отправитель. Создание пула и первый депозит — по договорённости (вариант: проект); approve — каждый свой; вывод — выводящий. Газ — в ETH, плательщика фиксируют до запуска.
  • LP-токены: в V2 их получает вносящий автоматически. Держатель — по согласованию (мультисиг сторон или сплит пропорционально вкладам); вывод ликвидности — только по совместному решению. Без этого пул не создаётся.
  • Стартовая цена wAGT (здесь 0,0005 WETH) — параметр: стороны выбирают и фиксируют до создания пула.

Кто что вносит
  • AGT в резерв моста вносит проект; wAGT выпускается только под заблокированные AGT (обратный выкуп — через burn).
  • wAGT в пул вносит проект (обеспеченные, из того же выпуска).
  • USDC в пул вносит партнёр. Бюджет проекта — 0 USDC.
LP-токены и вывод
  • Доли LP-токенов и право вывода ликвидности стороны согласуют до запуска (вариант: пропорционально вкладам, вывод — только по совместному решению).
  • Без согласованных долей и порядка вывода пул не создаётся.
